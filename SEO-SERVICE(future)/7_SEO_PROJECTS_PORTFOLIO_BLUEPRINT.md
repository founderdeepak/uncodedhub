## Project #1: Full-Scope SEO Audit

### Objective
Analyze any public business website, identify organic search bottlenecks across technical, on-page, speed, and indexing vectors, and deliver an actionable fix roadmap.

### Audit Checklist & Diagnostic Parameters

```
1. Crawlability & Indexing
   ├── robots.txt directives & bot accessibility
   ├── XML Sitemap syntax, HTTP status, and sitemap index linkage
   ├── Canonical tags (self-referential & cross-domain)
   └── HTTP status codes (301, 302, 404, 500 chains)

2. Technical & Performance
   ├── Core Web Vitals (LCP < 2.5s, INP < 200ms, CLS < 0.1)
   ├── Mobile viewport responsiveness & viewport tag hygiene
   ├── SSL/TLS enforcement (HSTS, mixed content flags)
   └── Prerendered HTML accessibility for non-JS bots

3. On-Page & Semantic Architecture
   ├── Meta title presence, character count (50-60 chars), & keyword placement
   ├── Meta descriptions (120-155 chars) with clear searcher intent
   ├── Single <h1> per page with logical <h2>/<h3> hierarchy
   ├── Image alt attributes, WebP/AVIF compression, explicit width/height
   └── Internal link hygiene (anchor text diversity, broken link resolution)
```

### Problem-to-Recommendation Matrix

| Discovered Problem | Root Cause | High-Impact Recommendation | Implementation Priority |
|:---|:---|:---|:---:|
| **Missing / Truncated Meta Titles** | Template default or missing page title tag | Write unique, intent-driven titles: `[Primary Keyword] — [Brand / Value Prop]` under 60 chars. | **HIGH** |
| **Slow Mobile Loading (LCP > 4.5s)** | Unoptimized JPEG/PNGs, render-blocking JS plugins | Convert images to WebP/AVIF, defer non-critical JS, prerender critical CSS. | **HIGH** |
| **Unindexed Service Pages** | `noindex` tag, orphan page, or robots block | Remove errant robots disallows, link from main navigation, submit to Google Search Console. | **CRITICAL** |
| **Broken Internal Links (404)** | Deleted legacy URLs or typo in anchor href | Update internal links to current destination or set 301 permanent redirects. | **MEDIUM** |
| **Missing Schema Markup** | No JSON-LD node in `<head>` | Inject `LocalBusiness`, `Organization`, or `Service` structured data. | **HIGH** |

## Project #4: High-Performance On-Page SEO

### Case Study Template & Optimization Hierarchy
*Applied to Target URL: `https://example.com/service-page`*

```html
<!-- 1. Metadata Optimization -->
<title>Invisalign in Chicago: Transparent Pricing & 3D Scans | Dental Studio</title>
<meta name="description" content="Looking for Invisalign in Chicago? Get custom clear aligners with zero down-payment options, digital iTero 3D scans, and dedicated doctor care. Book today.">
<link rel="canonical" href="https://example.com/services/invisalign/">

<!-- 2. Heading Architecture -->
<h1>Invisalign Clear Aligners in Chicago</h1>
<p class="answer-first">Direct, quotable summary answering timeline, pricing, and comfort...</p>

<h2>How Clear Aligners Straighten Teeth Without Metal Braces</h2>
<h3>Digital 3D Smile Simulation</h3>
<h3>Custom-Milled Aligners & Bi-Weekly Trays</h3>

<h2>Invisalign Cost & Flexible Financing in Chicago</h2>
<h3>Insurance Coverage & Health Savings Accounts</h3>
<h3>Monthly Payment Plans</h3>

<!-- 3. Image SEO Optimization -->
<img src="/images/invisalign-before-after.webp" 
     alt="Before and after clear aligner results for adult teeth crowding in Chicago" 
     width="800" height="600" loading="lazy">
```

### On-Page Optimization Standards
1. **Title Tag:** Primary Keyword in first 35 characters | Compelling Value Hook | Brand Name.
2. **Meta Description:** Active verb opening | Clear benefit | Direct Call to Action (under 155 chars).
3. **Answer-First H2/H3 Structure:** Every H2 answers a specific search query directly in the first 2 sentences.
4. **Internal Link Siloing:** 3-5 contextual links pointing up to the Pillar Page and horizontally to sister service pages.
5. **Image SEO:** WebP format, descriptive hyphens in filename (`chicago-invisalign-treatment.webp`), descriptive alt text.

## Project #7: Full-Lifecycle SEO Website Build

### The 7-Stage Execution Pipeline

```
  Stage 1: Keyword & Competitor Architecture
     │
  Stage 2: Semantic Information Architecture & URL Silos
     │
  Stage 3: Technical Foundation (React/Vite, Zero-Bloat CSS)
     │
  Stage 4: On-Page Optimization (Titles, Answers, Headings, Schema)
     │
  Stage 5: High-Converting Content & Lead Gate Integration
     │
  Stage 6: Google Search Console, Bing Webmaster, & IndexNow Verification
     │
  Stage 7: Continuous Measurement (Impressions, Clicks, Ranking Grid)
```

### The 7 Rules for Sustainable Organic Growth
1. **Never build on bloated foundations:** Avoid 35+ WordPress plugins that destroy mobile LCP.
2. **Write for the impatient human first, the bot second:** Direct answers win both Google AI Overviews and human conversions.
3. **Own your brand entity:** Declare clear, unambiguous Organization and LocalBusiness schema linked to verified profiles.
4. **Build internal linking bridges:** Every supporting article must pass page authority to a commercial revenue page.
5. **Enforce canonical discipline:** A single canonical version per page eliminates duplicate content penalties.
6. **Prioritize mobile 4G speeds:** In urban markets, mobile speed is the primary algorithmic and conversion filter.
7. **Track what matters:** Measure pipeline conversions and booked consultations, not just vanity impressions.
