# Uncoded Hub — Canva Charts & Data Visualization Guide

In **Canva Business**, you can build dynamic charts (Bar, Line, Donut, Comparison) connected directly to Google Sheets or manual input. Use this guide to ensure all data graphics match Uncoded Hub's Swiss architectural aesthetic.

---

## 1. Chart Types & Best Uses

| Chart Type in Canva | Best Use Case for Uncoded Hub | Recommended Palette |
| :--- | :--- | :--- |
| **Progress Ring / Donut** | 100/100 Core Web Vitals score, SEO audit scores | `speed_and_performance_audit` |
| **Horizontal Bar Chart** | Page load speed comparison (e.g., Uncoded Hub 0.4s vs Competitor 4.8s) | `conversion_comparison` |
| **Column Chart** | Lead generation growth, client revenue before vs after | `primary_high_contrast` |
| **Line Chart** | Organic search impressions, traffic compounding over 12 months | `monochrome_architectural` |

---

## 2. Formatting & Styling Rules in Canva

1. **Colors**:
   - **Hero Value / Winner**: Always use International Flame (`#FF3B00`) or 100/100 Green (`#22C55E`).
   - **Baseline / Competitor / Average**: Use neutral gray (`#D1D5DB` or `#6B7280`).
   - **Never** use multi-colored rainbow charts unless showing 4 distinct niche categories.
2. **Typography in Charts**:
   - Set Chart Title to **Cormorant Garamond** (Bold).
   - Set Axis labels, numbers, and legends to **Space Mono** (Regular).
3. **Gridlines & Borders**:
   - Keep gridlines subtle: use `#E5E5E0` at 1 px stroke.
   - Remove heavy black borders around chart frames.
4. **Data Density**:
   - Keep data points minimal (3 to 6 bars maximum). Thumbnail charts should communicate the core metric in less than 2 seconds of viewing time.
