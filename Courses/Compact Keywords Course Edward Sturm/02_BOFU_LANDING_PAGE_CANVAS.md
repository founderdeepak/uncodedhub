## 4. Word Count & Moz Grader Audit Checklist
- [ ] Word count is between **400 and 500 words** (Sweet spot: ~415 words).
- [ ] Target keyword is in the **URL slug**.
- [ ] Target keyword is in the **Page Title** (as early as possible).
- [ ] Target keyword is in the **H1**.
- [ ] Target keyword is in the **first sentence of the first paragraph**.
- [ ] Target keyword is in the **alt text of the first image**.
- [ ] Target keyword is in the **Meta Description**.
- [ ] Tone is **neutral, confident, and factual** (zero exaggerated hype).
- [ ] Moz On-Page Grader score is **96–98** (Never artificially force 100).
